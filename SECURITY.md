# Política de segurança

## Versões suportadas

Este projeto está em desenvolvimento ativo. A branch `main` representa o estado principal do repositório; não são prometidas correções de segurança para versões antigas ou branches experimentais.

| Versão | Suporte |
| --- | --- |
| `main` | Em desenvolvimento |
| Releases antigas | Sem garantia de suporte |

## Comunicação responsável

Se encontrar uma vulnerabilidade, **não abra uma issue pública** com detalhes exploráveis. Contacte o proprietário através do [perfil GitHub](https://github.com/Antonio-Buela2006) e inclua uma descrição privada do problema, o impacto potencial, os passos mínimos para reprodução e uma sugestão de mitigação, se disponível.

Não envie credenciais, dados pessoais reais, dumps de bases de dados ou tokens. Use exemplos fictícios e remova quaisquer segredos antes de partilhar logs ou capturas de ecrã.

O objetivo é confirmar a receção, reproduzir o problema, preparar uma correção e comunicar a resolução de forma responsável. O prazo de resposta pode variar porque o projeto é mantido como trabalho em evolução.
