# KULTURA Dispatch

Blog editorial de notícias sobre cultura, música, tecnologia e opinião, criado em React + Vite + Tailwind CSS.

## Conteúdo

A homepage apresenta um artigo em destaque, ticker editorial, filtros por categoria e pesquisa de artigos. Cada notícia tem uma página própria com metadados, imagem de arquivo, leitura, partilha, guardar artigo e artigos relacionados.

## Desenvolvimento local

```bash
pnpm install
pnpm dev
```

Para verificar os tipos e gerar a build:

```bash
pnpm run check
pnpm run build
```

## Direção visual

A identidade segue o conceito **Broadcast Zine**: papel marfim, tinta carvão, vermelho Signal Red, tipografia condensada e metadados em monoespaçada, com referências visuais a rádio, imprensa e cultura musical.
